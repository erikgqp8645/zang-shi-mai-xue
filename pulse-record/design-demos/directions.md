# 三方向 · 方向卡（2026-11-21）

题材：臧氏脉学脉象记录工具（临床记录 + 依脉用方知识库）。
受众：中医从业者／学习者，桌面录入选穴、手机床旁核对。
同一份内容：示例·少娟 / 5 次记录 / 命中 35 条 / 常驻 2 条。

## 已做完整版的三张

### 方向一 · 医案册页（dir-1.html）
- 逻辑与来源：最佳设计师｜吕敬人（书籍编排，书眉与批注的空间关系）
- 借的机制：**竖排书眉列 + 正文页 + 页边批注**三栏的读法；标题列占宽约 7%，批注栏约占 24%
- 不借的：他的纸张肌理与朱红印色；这次纸色、朱砂仍取自本工具现有设计令牌（宣纸/墨/朱砂/赭石）
- 主角素材：记录表本身（部位列赭色块）+ 右栏批注
- 骨架：92px 竖排书眉 ｜ 通栏病案表格 ｜ 316px 批注栏
- 胆量花在：右下角那方「脉案」朱印与竖排姓名
- form 来自内容的哪里：中医病案本来就是册页——书眉、方脉、批注

### 方向二 · 诊台（dir-2.html）
- 逻辑与来源：现实参照｜临床类记录工具（数据优先、无纹理、单一强调色）
- 借的机制：**一屏两区**（主表 70% + 常驻侧栏）+ 底部三步状态条；当前记录整列淡染
- 不借的：它的蓝色系与圆角尺寸；这次用中性白 + 靛青单色，圆角 6px
- 主角素材：表格的对齐与密度（无装饰）
- 骨架：顶部条（患者/日期/动作）｜ 主表 ｜ 360px 判读栏 ｜ 底部三部曲
- 胆量花在：把表格做到极准（斑马纹、组界、当前列）
- form 来自内容的哪里：把脉就是对着格子做判断——界面就该是一张精确的表

### 方向三 · 分步向导（dir-3.html）
- 逻辑与来源：现实参照｜健康类 App 的分步流程（Apple Health 式单列引导）
- 借的机制：**一屏一件事**、顶部三段进度、卡片内大点击区（≥44px）
- 不借的：它的渐变与圆角 20px；这次用米白 + 深松绿，圆角 14px
- 主角素材：寸/关/尺 三组录入卡
- 骨架：单列 700px，进度条 → 日期 → 摸脉卡 → 判读卡 → 主操作
- 胆量花在：手机上一个拇指就能录完一次
- form 来自内容的哪里：开方三部曲本来就是三步，界面按三步走

## 未做完整版的三个备选
- **备选 A（原研哉式极简）**：一屏只有表格，判读收进抽屉；留白极大。风险：信息密度不够，临床要来回切。
- **备选 B（瑞士网格）**：强网格、大字号反差、红黑两色。风险：与中医质感的距离最远。
- **备选 C（终端/仪表盘）**：等宽字体、状态灯、键盘优先。风险：用力过头，去掉这套手法后信息并不会更清楚。

## 打磨记录（第一轮，每版三条）
- dir-1：手机端三步换行断裂 → 改单行紧凑；部位列过饱和 → 降饱和；手机端印章挤压标题 → 收小
- dir-2：表头「左/右」压在日期之上 → 互换；colgroup 与列数不符 → 补齐 8 列并定宽；底部条吊在 100vh 外 → 贴内容
- dir-3：取法标签缺失、部位名只出现一次 → 每组加组头、每行加 浮/中/沉；CTA 悬浮遮住卡片 → 取消 sticky；值块过宽 → 加字重与底色区分
- 说明：本机未装 Python 版 playwright，`design_lint.py` 跳过；改用 Playwright MCP 截图肉眼对照，桌面 1440 与手机 390 各一张，均无横向溢出。
