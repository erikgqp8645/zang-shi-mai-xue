## 1. 微信后台 ·《用户隐私保护指引》（⬜ 不用勾隐私类型）

**位置**：小程序后台 → 设置 → 用户隐私保护指引 → 去更新。

### 1.1 隐私接口 —— **一项都不用勾**

| 勾选 | 对应接口 | 触发时机 |
|---|---|---|
| （无） | —— | 2026-11-05 起上线包**不再调用任何隐私接口**：原来的「存到相册」「复制 Markdown／CSV」三个导出选项，连同 `saveImageToPhotosAlbum`、`setClipboardData` 一起删掉了 |

**为什么不用勾**：勾了就是「声明了没用」。微信审核会对照声明与实际调用，
多勾一项反而可能被当成不实声明。

⚠️ **例外**：**原生回退工程 `miniprogram/` 里仍带**这两个接口（它是本地兜底，不上传）。
若哪天改用它上线，才需要勾「相册（仅写入）」与「剪切板」。

### 1.2 不用勾的（及为什么）

这些**代码里根本没有调用**，勾了反而是「声明了没用」：

| 不勾 | 依据 |
|---|---|
| 位置信息 | 无 `getLocation` / `getFuzzyLocation` 调用 |
| 通讯录 | 无 `chooseContact` / `chooseAddress` 调用 |
| 摄像头 / 麦克风 | 无 `camera` / `record` 相关调用 |
| 读取相册 | 无 `chooseMedia` / `chooseImage` 调用（连写入的也没有了） |
| 手机号 | 个人主体不支持 `getPhoneNumber`；代码里没调 |
| 昵称 / 头像 | 无 `getUserProfile` / `getUserInfo` / `chooseAvatar` 调用 |
| 蓝牙 / 通讯 / 交易 | 无相关调用 |

### 1.3 收集的用户信息

如实地写「用户输入内容」这一类：

| 项 | 怎么写 |
|---|---|
| 用户输入内容 | > 使用者自行录入的病例资料：患者姓名、就诊记录、脉象格值、用药记录。仅用于保存与展示使用者自己的脉诊记录，不用于画像、不用于广告。 |
| 账号信息 | > 使用者自设的登录名、显示名称；密码以 scrypt 加随机盐的哈希形式存储，服务器上不保存明文密码。 |

**不要**勾「微信昵称」「微信头像」「手机号」—— 我们都没取。

### 1.4 第三方 SDK

当前 **TRANSPORT = 'request'**，只连使用者自己的服务器，**没有第三方 SDK** → 这一栏不用填。

⚠️ **例外**：如果备案迟迟不下来，你决定改走 `TRANSPORT='cloud'`（`wx.cloud.callFunction`，绕过合法域名校验），
那就**必须**在这里补声明「腾讯云 CloudBase」及用途 —— 那是第三方 SDK，属于审核必查项。

### 1.5 保存期限与删除方式

| 项 | 怎么写 |
|---|---|
| 保存期限 | > 账号与病例数据在服务器上持续保存，直至使用者自行删除或注销账号。 |
| 删除方式 | > 使用者可在小程序内逐条删除病例记录；「我的」页可解绑微信身份；注销账号（连带删除全部数据）请联系运营者。 |

### 1.6 配完之后的两件事

1. **基础库最低版本**（后台 → 开发管理 → 基础库）建议设 **2.32.3 或以上** ——
   低于这个版本微信不会自动弹隐私协议，调用隐私接口会直接失败。
   （现在上线包**不调隐私接口**了，这条只是以防以后加功能。）
2. 微信会在**首次调用隐私接口时自动弹协议**。目前**没有这样的调用**，所以不会有弹窗 ——
   以后若加回导出功能，代码里要重新识别两种错误并给出可操作的提示。

## 2. 微信后台 · 服务器域名（⬜ 等备案）

**位置**：小程序后台 → 开发管理 → 开发设置 → 服务器域名 → **request 合法域名**。

微信的硬要求：

- 必须是 **https**
- 域名**必须已 ICP 备案**（主体与小程序主体一致）
- **不能带端口、不能是 IP**

所以开发阶段用的是 `http://127.0.0.1:5178` / 局域网 IP，**上线包不能带着它**。
上线构建时注入正式域名：

```bash
cd pulse-record
PULSE_API_BASE=https://<你的备案域名> npm run mp:taro:build
```

注入已实测：产物 `common.js` 里的默认地址会变成注入的域名；
不注入就是本机默认值（`src/utils/config.ts`）。
「我的」页里也能改（存在本地存储），所以联调包与正式包可以并存。

## 7. 审核常见退路（对照着查）

| 症状 | 根因 | 处置 |
|---|---|---|
| 真机所有请求超时 / 连不上 | request 合法域名没配，或用了 IP／端口／http | §2 |
| 隐私弹窗不出现 | 现在**没有隐私接口调用**，不弹是正常的 | §1.1 |
| 审核说「找不到隐私政策」 | 小程序内没有可见入口 | 已加（§4.2） |
| 审核说「功能与类目不符」 | 类目选错 | §3 |
| 提审提示需要手机号／用户信息授权 | 个人主体不支持，或代码里没调 | 不用管（§1.2） |
