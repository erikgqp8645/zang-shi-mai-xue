臧氏脉学 · 用方知识库

怎样填写这份工作簿

它是人工编辑层——程序真正读的是仓库里的 src/content/*.json。 改完工作簿，跑一条命令转回 JSON，网站和小程序就跟着变了。 填错就是显示错，所以每一步都有据可依。

01

主流程

从拿到资料到改完落地，五步。

1

拿到原文

讲稿 2010／讲义 2026-10／同和堂版方剂表。

2

判断去哪填

改格位、关系、还是条件文字——去处不同，见下节。

3

照抄原文

不改写、不补写。留空＝原文没写。

4

转回 JSON

写回机器真正读的那层。

npm run content:json
5

校验与回归

确认没丢东西，也没改坏别处。

content:check → npm test
02

改什么 → 去哪张表

这一步决定了你只动一张表，还是两张。

脉象图的格位要求用字、组号、备注、柔性
矩阵 sheet
P01- … P50-
矩阵是格位的唯一编辑面。九行：寸关尺 × 浮中沉，左右手两列。改完只动这一张。
关系型要求「任意格变脉」「尺脉不平衡」这类画不成单格的
脉象图·关系
39 行
矩阵表头区那份标着「（只读）」，是副本。真源在这张表里 —— 同一关系有多个探针时每行各填自己的。
触发条件／路线／出处条目的元信息
用方条目
61 条
矩阵表头区同样是只读副本。条件文字是原文用语，不改写、不概括。
方剂的组成／服法／加减／禁忌讲稿 2010
方剂·讲稿2010
30 方
剂量是比例制（「熟地5」）。加减一格多条时一条一行。
成方的组成与剂量同和堂版
成方·同和堂版
49 方
单位是克（「茯苓12」）。与讲稿的比例制两套，不可换算、不可合并。

⚠️ 矩阵 sheet 名里的序号 P01、P02… 不要改——那是条目在「脉象图·条目」表里的位置。 条目 ID 最长 35 字符，Excel 的 sheet 名上限 31 会截断，所以靠序号认人。

04

四条格式规则

这四条错了，转回时不会报错，但内容会错。

分隔符

一格多条 → 一条一行

数组用单元格内换行分隔。
讲稿的方名自带顿号——「柴鳖骨（柴胡、鳖甲、地骨皮）」， 用顿号或逗号切必然切错。

用字 vs 符号

矩阵里填用字，不是代码

++ 是「允许的取值集合」，大 才是原文写下的词。 照抄「脉象用字」表第 1 列；写了表里没有的字，转回时会报错。

且 / 或

组号决定且或

留空＝本格单独成立；同号＝一组（且）；异号＝不同组（或）。 左右两列各自独立。

两套单位

比例制 ≠ 克

讲稿是比例制（熟地5），同和堂版是克（茯苓12）。 不换算、不合并，也不替读者选一个。

05

报错了怎么改

还原脚本宁可报错也不猜。看到信息照下表改。

主键（id）为空
那一行的 ID 被清空了 —— 补回，或删掉整行
主键「xxx」重复
两行用了同一个 ID —— 改掉其中一个
用字「xxx」不在「脉象用字」表里
写了表里没有的用字 —— 照抄「脉象用字」表第 1 列
组号「xxx」不是正整数
组号只能是数字 —— 留空或填 1、2、3
表头写的条目ID 是「xxx」，但序号 NN 对应的是「yyy」
矩阵 sheet 被改名或移动了 —— 序号不能改
矩阵里没有条目「xxx」的 sheet
少了一张矩阵 —— 50 条条目都要有

想先练一遍？

  1. 打开 content/示例-填写示范.xlsx —— 主工作簿的副本，5 格故意留空并标黄
  2. 每格旁边有批注：这一格该填什么、依据哪句原文
  3. 填完验收：npm run content:exercise:check，逐格告诉你对不对

⚠️ 别对练习册跑 npm run content:json —— 里面有故意留空的格子， 写回 JSON 会把内容真丢掉。程序会直接拒绝并指路到验收脚本。
